# Sources and Further Reading

This course draws on four books alongside the structure of the RPM Fast-Track course. All the ideas below are summarised in my own words; read the originals for the full argument.

---

## Tony Robbins — *Awaken the Giant Within* (1991)

**What it contributes:** the psychology underneath the method — why we act, why we don't, and how to change state.

| Idea | Where it appears |
|---|---|
| The long list of goals, with timeframes and reasons | Module 1, Step 0 |
| Shoulds and musts; raising your standards | Module 1 |
| Being stuck in one time frame; urgency vs importance | Module 2 |
| Overwhelm as a signal to choose | Module 2 |
| Pain and pleasure as the two sides of a Reason | Module 3 |
| Values as the test of a Result | Modules 3 and 7 |
| Learning from others to compress time ("Borrow") | Module 5 |
| Questions as a lever on state; the problem-solving sequence | Module 6 |
| Rules: easy to feel good, hard to feel bad | Module 7 |
| Morning and evening questions | Module 7, Daily Card |
| The ten-day mental challenge | Module 7 |

**My view:** the most useful book of the four for this course. Its central claim — that how you feel decides what you do, and that you can change how you feel on purpose — is the reason the Reason question matters. The tone is intense and very American; I've kept the substance and calmed the delivery.

## Laura Stack — *What to Do When There's Too Much to Do* (2012)

**What it contributes:** the operational discipline — reduction, triage, processing, boundaries.

| Idea | Where it appears |
|---|---|
| Reduction before speed | Module 2 |
| The Not-To-Do list | Module 2, Leverage Ledger |
| The 6-D system (Discard, Delegate, Do, Date, Drawer, Deter) | Module 4, Stage 2 |
| Master list vs daily list | Module 4 |
| Triage (P1–P4) | Module 4, Daily Card |
| Saying no well | Module 4 |
| Internal vs external distractions | Module 6 |
| Capacity: sleep, food, movement, happiness | Module 6 |
| Closing the loop on bottlenecks | Module 5 |

**My view:** the most practical of the four. It's written for a corporate office, so some sections (filing, voicemail) feel dated, but the core tools carry over cleanly to owners and commercial leaders. The Not-To-Do list and the 6-D sort are the two I'd keep if I could keep only two.

## Tracy Weaver — *Time Management and Productivity* / *80/20 Success Series* (same text)

The two files you sent contain the same book.

**What it contributes:** short, usable tactics.

| Idea | Where it appears |
|---|---|
| Clock time vs actual time | Module 2 |
| A daily appointment with yourself | Module 4 |
| Plan before you open the inbox | Module 4 |
| Parkinson's law; halving estimates | Module 4 |
| Clarify the outcome before every meeting | Module 3 |
| The 80/20 principle, applied to clients and products | Modules 3 and 5 |
| 45-minute single-tasking; ten-minute gaps | Module 6 |
| What will it cost me not to do this? | Module 3 |

**My view:** thin, but the tactics are sound. Where I've departed from it is the argument for "a constant state of urgency." That suits some temperaments, but it reads as pressure, burns people out, and doesn't fit a calm, premium way of working. The course uses chosen deadlines and protected time instead of permanent urgency.

## Joe Dispenza — *Becoming Supernatural* (2017)

**What it contributes:** the inner practice — mental rehearsal, emotional state, breaking automatic patterns.

| Idea | Where it appears |
|---|---|
| Feeling the emotions of a result before it arrives | Module 7, morning rehearsal |
| Heart-focused breathing with an elevated emotion | Module 6, Restoratives Menu |
| Living on automatic; choosing a different response | Module 6 |
| Walking meditation — carrying the practice into the day | Module 7 |
| Mind movies → a simple quarterly vision reel | Module 7, Quarterly Review |

**My view, honestly:** the practices are valuable; much of the explanation isn't. Mental rehearsal, slow breathing and deliberately cultivating gratitude are well-supported, widely used tools. The book's framing — quantum fields, programming the autonomic nervous system, healing claims, the pineal gland — goes well beyond what the science it cites actually shows. I've kept the practices and left out the metaphysics. If you put this course in front of clients or a team, I'd recommend you do the same: it protects the credibility of everything else in it.

## The original course

Tony Robbins, *RPM (Rapid Planning Method) Fast-Track Course*, Robbins Research International. This course follows its overall arc — outcome before activity, purpose as fuel, leverage, time and state, long-term rituals — with an independent framework, language and set of tools.
